# Notes — free AI desktop assistant

Download Notes from **https://www.bitecodes.com/notes**.

This repository only hosts the installers. Pick the latest release on the right:

| Computer | File |
| --- | --- |
| Mac with Apple Silicon (M1 and newer) | `Notes-<version>-arm64.dmg` |
| Mac with Intel | `Notes-<version>.dmg` |
| Windows 10/11 (64-bit) | `Notes-Setup-<version>-x64.exe` |
| Windows on ARM | `Notes-Setup-<version>-arm64.exe` |

**First launch:** the builds are not yet code-signed. On a Mac, right-click Notes in Applications and choose **Open**. On Windows, click **More info → Run anyway**.

Then click **Sign in with Bitecodes** — a free Bitecodes account is all you need.
